The problem

In Egypt, a lot of money moves between people, not categories.

A loan to a friend. Rent a cousin covered. A wedding gift you'll return one day. Most of it lives in people's heads or in a paper daftar, and expense trackers don't help because they're built around categories.

A balance per person

“They owe you”, “you owe them” or “settled”, with partial repayments rolled in.

Built for non-accountants

Plain language, calm visuals, no ledger jargon.

Engineering highlights

Offline-first. Private by default.

☁️

Offline-first sync

A local DB is the source of truth. An outbox is written in the same transaction, with revision guards and manual conflict resolution for money records.

🔒

App lock

PIN hashed with PBKDF2, biometrics, auto-lock on inactivity and screenshot protection.

💱

Honest money math

Integer minor units plus ISO 4217 currency. A missing exchange rate blocks the total instead of guessing it.

📷

On-device ML

OCR runs locally with ML Kit, so images never leave the phone. AI keys stay in secure storage.
