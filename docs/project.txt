# 1. THE RAW PRODUCT IDEA

I want to build a mobile application for the Egyptian market.

The first major problem the application should solve is managing money exchanged between people.

In Egypt, there are social occasions and situations where people give each other money, gifts, contributions, or financial amounts. There are also situations where I may give someone money and expect it back, or someone gives me money and I need to remember that I owe them.

Examples:

- Someone gave me 2,000 EGP.
- I gave someone 1,500 EGP.
- Someone still owes me 1,000 EGP.
- I still owe someone 700 EGP.
- During a wedding/engagement/birthday/social occasion, I received money from several people.
- During another occasion, I gave money to several people.
- I want to know exactly who gave me money, how much, when, why, and whether the amount was settled.
- I want to know who I gave money to and whether they still owe me.
- I want a complete history for every person.

The user should be able to create a person/contact and record transactions against them.

For example:

Ahmed
- Gave me: 2,000 EGP
- I gave him: 500 EGP
- Net: Ahmed owes me 1,500 EGP

Another example:

Mohamed
- I gave him: 3,000 EGP
- He returned: 1,000 EGP
- Remaining: 2,000 EGP

The application should make these relationships extremely easy to understand.

# 3. PAPER / IMAGE → AUTOMATIC TRANSACTION ENTRY

This is a very important feature.

Sometimes the user may have a physical paper containing records such as:

Ahmed — 1000
Mohamed — 500
Mahmoud — 2000
Omar — 750

The user should be able to:

1. Take a photo.
2. Upload an existing image.
3. Crop/rotate/enhance the image.
4. OCR extracts the text.
5. AI understands the structure.
6. Detect:
   - Person name
   - Amount
   - Direction
   - Date if available
   - Occasion if available
   - Notes if available
7. Show a REVIEW screen.
8. User confirms/corrects the extracted data.
9. Transactions are saved.

IMPORTANT:

Never automatically save financial transactions from OCR without user confirmation.

The user must be able to correct:

Ahmed → Ahmed Ali
1000 → 1,000 EGP
Received → Given

The system should display confidence levels where appropriate.
